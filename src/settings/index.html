Spotify

Çalan şarkıyı gösterir; oynat, duraklat, ileri ve geri sar.

Basit mod Kurulum yok Spotify masaüstü uygulaması açıksa şarkı adı ve sanatçı otomatik görünür. Kontroller Windows medya tuşlarıyla çalışır, Free hesapta da olur. Ekstra bir şey yapmana gerek yok.

Gelişmiş mod: albüm kapağı ve ilerleme çubuğu

Kurulum
  1. developer.spotify.com/dashboard adresinde Create app de.
  2. Redirect URI olarak şunu ekle: http://127.0.0.1:8974/callback
  3. “Web API” kutusunu işaretle, kaydet. Client ID'yi aşağıya yapıştır.
Not: Spotify, geliştirici modundaki uygulamalarda hesap sahibinin Premium olmasını şart koşuyor. Premium değilsen basit mod kullanmaya devam et.

AI Kullanımı

Claude Code

Claude Code kullanımını izle Anahtar gerekmez Bilgisayarındaki Claude Code oturum kayıtlarından (~/.claude/projects) 5 saatlik penceredeki token kullanımını ve sıfırlanmaya kalan süreyi hesaplar. Veriler bilgisayardan çıkmaz.
5 saatlik token limitiPlanına göre kendi belirlediğin bir üst sınır. Yüzde göstergesi ve uyarı için kullanılır. 0 = kapalı.
